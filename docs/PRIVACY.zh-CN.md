# 隐私与权限

MacTV 不要求注册自己的账号。应用中的“账号”指各内容平台的独立登录。

## 本机数据

应用目录位于当前用户的 `~/Library/Application Support/MTV`：保存来源配置、索引、匹配缓存、图片、观看记录和平台登录。

新凭证使用权限受限的本机文件存储：目录 700、文件 600，不写入 Apple 钥匙串。这不是加密保险箱，不能防御当前用户下的恶意进程。旧版 MacTV 自有钥匙串记录有受控迁移路径；应用不会扫描其他应用的任意钥匙串记录。

## 影片目录

扫描与播放读取用户选择的来源，不改写原影片或 NFO。macOS 可能要求外置磁盘、网络宗卷或目录访问确认。目录授权与“完整磁盘访问”不是同一范围，正常使用应优先授予所需来源的权限。

## Chrome 导入

只有用户在对应平台选择导入时才读取选定 Chrome 资料中的该平台 Cookie。默认禁止系统弹窗；缺少权限时，先在应用内说明，用户选择“授权并导入”后才请求系统确认。

Chrome Safe Storage 由独立的 MTVChromeBridge 原生组件读取。它没有 MTVCore 或界面依赖，普通主程序改动不改变该组件的代码；安装检查会报告组件内容身份是否保持。组件只接受同一签名证书下、标识为 MacTV 主程序的有效父进程；主程序也验证组件的签名、标识和证书。任意程序、插件或浏览器扩展不能直接调用这个读取模式。

组件只读取这一条现有钥匙，不修改访问列表、不创建凭证、不访问网络。响应只通过匿名管道送回原生主程序，不进入插件、日志或文件；应用不缓存 Chrome 解密钥匙。组件处理完即退出，关闭登录页可终止当前读取；主程序退出时组件也自行退出，避免留下授权窗口。

本机读取失败时显示原因，或提供扫码/扩展导入选项。不会改用 SSH、复制浏览器数据库或扩大到其他平台来绕过系统限制。导入后需验证平台会话，再保存到 MacTV 自己的本机凭证记录。

## 网络

访问的服务包括所选媒体来源、平台模块声明的端点、已配置的影视资料服务和海报来源。TVmaze 查询不需要 Token；TMDB Token 只发送给 TMDB 的认证接口。不要将含 Cookie、Token 或带凭证的视频 URL 的日志公开上传。

## 开发测试

`--enable-control` 可临时开启当前用户的本机控制接口，默认关闭，不安装常驻服务、不开放网络控制端口。状态与最近事件保存在权限受限的 Control 目录，可能包括影片标题与来源。账号导入还需独立开关，采用非交互读取；不能通过接口自动授予系统权限或导出登录凭证。

测试结果可能包含媒体标题、来源路径或截图，保留在本机，不应直接提交到公开仓库。公开报告应只保留无个人数据的结果摘要。
