# Get started with MacTV

[简体中文](GETTING-STARTED.zh-CN.md)

## Install and set up

Download an installer from [Releases](https://github.com/Force1ess/MacTV/releases) and drag MacTV.app to Applications. Follow setup to add a library, connect content services, and choose an audio output.

A directional remote and a trackpad are recommended for a TV-connected Mac. Audio can follow the system output or use your TV or speakers directly.

## Add your movies

In **Settings → Video Sources**, add a movie folder or enter an SMB share address and account. Allow access when macOS asks to open an external disk or network folder.

Movies and series appear on the poster wall after scanning. New downloads refresh automatically; **Rescan Videos** also starts a scan. Use the movie's menu to correct a match.

## Sign in to Bilibili and Quark

Open the service and choose QR sign-in. Scan the code with its mobile app and confirm. You can also import a session from Chrome on this Mac.

### Import from Chrome

1. Sign in to Bilibili or Quark in Chrome on this Mac.
2. In MacTV, choose **Import from Chrome** and select the Chrome profile.
3. If Full Disk Access is needed, open **System Settings → Privacy & Security → Full Disk Access**, add MacTV from Applications, and enable it. Quit and reopen MacTV.
4. The first import may show a **Chrome Safe Storage** prompt. Enter your login keychain password (usually your Mac login password) and choose **Always Allow** to make future imports easier.
5. Once signed in, browse recommendations, favorites, or cloud folders.

QR sign-in is available if you prefer not to enable Full Disk Access.

## Remote controls and text

| Input | Action |
| --- | --- |
| Arrow keys | Move focus; focusing a top navigation item switches sections |
| Enter / confirm | Open, play, or confirm |
| Esc / Backspace / back | Close the current menu and go back |
| C / menu | Open actions for the current item |
| On-screen keyboard Delete | Delete text |

During playback, Back first hides the controls, then exits playback. Audio and subtitle menus return to the playback controls first.

Text fields open an on-screen keyboard with Chinese pinyin support. Enable macOS Dictation and connect a microphone to use dictation. Some remotes need key mapping in their companion software.

## Playback and audio

Select a movie or video to play. The playback controls provide speed, audio tracks, subtitles, and seeking. Previously watched movies offer resume playback.

If your TV's HDMI output cannot be adjusted with system volume keys, use the TV remote or MacTV's playback volume control.

## Quark photos and Steam

Open photos directly from a Quark Drive folder. Steam UI opens an installed Steam in Big Picture mode and returns to MacTV when it closes.

Use plugin management to install, update, and remove apps, or add another plugin source.
