# Roadmap

[简体中文](ROADMAP.zh-CN.md)

Future updates focus on making MacTV more comfortable to use from the couch:

- Faster browsing and better matching tools for large media libraries.
- More control over subtitle appearance and playback preferences.
- A simpler plugin discovery and installation experience.
- A standalone Music plugin with library search.
- Broader remote compatibility and voice interaction.

Suggestions and feedback are welcome in [Issues](https://github.com/Force1ess/MacTV/issues).
