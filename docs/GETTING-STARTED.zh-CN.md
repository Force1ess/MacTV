# 开始使用 MacTV

[English](GETTING-STARTED.md)

## 安装与首次设置

从[发行版页面](https://github.com/Force1ess/MacTV/releases)下载适合的安装包，将 MacTV.app 拖入“应用程序”。打开后，按引导添加片库、连接内容服务，并选择声音输出。

连接电视后，建议准备一个方向键遥控器和触控板。声音可选择跟随系统，或单独输出到电视与扬声器。

## 添加影片

在“设置 → 影片来源”添加影片文件夹，或填写 SMB 共享地址与账号。macOS 询问是否允许访问外置硬盘或网络目录时，选择允许。

扫描完成后，电影和剧集会出现在海报墙。新下载的影片会自动刷新，也可以手动选择“重新扫描影片”。影片识别有误时，在影片菜单中重新匹配。

## 登录哔哩哔哩与夸克

打开对应应用，选择扫码登录，用手机客户端扫描电视上的二维码并确认；也可以导入这台 Mac 的 Chrome 登录。

### 从 Chrome 导入

1. 先在这台 Mac 的 Chrome 中登录哔哩哔哩或夸克。
2. 在 MacTV 选择“从 Chrome 导入”，选择对应的 Chrome 资料。
3. 如提示需要完整磁盘访问，打开“系统设置 → 隐私与安全性 → 完全磁盘访问权限”，添加“应用程序”中的 MacTV 并开启，然后退出并重新打开 MacTV。
4. 首次导入可能出现“Chrome Safe Storage”提示。输入登录钥匙串密码（通常与 Mac 登录密码相同），选择“始终允许”，以后导入更方便。
5. 登录完成后，即可浏览推荐、收藏或网盘目录。

若不想开启完整磁盘访问，可以使用扫码登录。

## 遥控与文字输入

| 按键 | 操作 |
| --- | --- |
| 方向键 | 移动焦点；停留在顶栏时切换栏目 |
| Enter／确定 | 打开、播放或确认 |
| Esc／Backspace／返回 | 收起当前菜单，返回上一级 |
| C／菜单 | 打开当前内容的操作菜单 |
| 屏幕键盘“删除” | 删除输入文字 |

播放时，返回键先收起控制栏，再退出播放；打开音轨、字幕等菜单时，先回到播放控制栏。

文字输入会打开屏幕键盘，支持中文拼音。需要听写时，先在 macOS 开启听写并连接麦克风。部分遥控器需要在其配套软件中设置按键映射。

## 播放与声音

选中影片或视频即可播放。在播放栏调整倍速、音轨、字幕和进度；再次打开看过的影片时，可以继续播放。

如果电视的 HDMI 输出无法用系统音量键调节，可以使用电视遥控器或 MacTV 的播放音量控制。

## 夸克图片与 Steam

在夸克网盘目录直接打开图片。Steam UI 可以打开已安装的 Steam 大屏模式，关闭后回到 MacTV。

在插件管理中安装、更新和移除应用，也可以添加新的插件来源。
