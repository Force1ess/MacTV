## 提交改动

先在 Issue 中描述使用场景、预期效果和复现步骤。提交 PR 时说明用户可以观察到的变化，以及使用的测试设备和系统版本；界面调整可以附上截图。

Swift 代码沿用两空格缩进。内置服务适配位于 `src/integrations`，共享协议和数据结构位于 `MTVCore`，开发工具统一放在 `tools`。独立插件在自己的仓库中构建与发布。

新增依赖请记录来源、版本和许可证。账号、会话和签名资料保存在开发环境中，提交的复现使用自建样本。

安全问题的联系方法见[安全说明](SECURITY.md)。
